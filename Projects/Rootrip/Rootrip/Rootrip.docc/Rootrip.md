# Rootrip

지도위에 펜을 이용해 그림이나 글씨를 입력해 메모를 하거나 영역지정, 경로검색을 할 수 있는 앱

#### Member

Dean, May, Ella, Way, Sana, Steve

---

## Solution Concept
잘 모르는 지역의 여행을 계획할때, 지도위에서 펜슬킷으로 영역을 지정하면, 그 영역 안에서 원하는 장소들을 탐색할 수 있도록 해서 그 지역을 파악하고, 여행 경험이 확장되도록 돕는 앱

---

### Key Features
- 지도 그림 그리기 기능
- 지도 영역 지정 기능
- 지도 경로 지정 기능
- 로그인 기능

### Code Architecture
- Repository Pattern
- MVVM Pattern
- MVC  Pattern
